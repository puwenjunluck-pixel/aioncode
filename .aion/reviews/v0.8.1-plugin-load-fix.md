# Review: v0.8.1 — 修复插件加载失败

## 根因与修复
v0.8.0 第一次真人 `/plugin install` 后 `claude plugin list` 显示 `✘ failed to load`，错误：「Duplicate hooks file detected: ./hooks/hooks.json ... loaded automatically」。根因：plugin.json 声明了 `skills`/`hooks` 字段，二者是 Claude Code 标准自动加载位置，显式声明导致重复加载。修复：删除两字段，manifest 变为纯元数据（对齐 superpowers plugin.json 结构）。version 0.8.0→0.8.1 以便 `/plugin update` 识别。

## 教训（已提取为规则）
`claude plugin validate` 只校验 manifest schema，不模拟运行时加载——三轮评审 + 多次 validate 全部通过，却漏掉这个加载失败。新规则：验收插件必须以 `claude plugin list` 加载状态为准。
