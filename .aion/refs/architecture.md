# Project Architecture

> Updated: v0.6.4 (2026-03-25)

## Tech Stack
- Language: Python 3.10+ (backend + CLI), JavaScript (frontend), Bash (install/uninstall), Markdown (commands)
- Framework: FastAPI + uvicorn (dashboard backend)
- Frontend: Vanilla JS + CSS3 (no framework, no bundler)
- Database: N/A (JSON file persistence — `projects.json`)
- Test Framework: pytest (6 test files)
- Linter: ruff
- Build Tool: setuptools + wheel (`pyproject.toml`)
- Dependencies: fastapi >= 0.115, uvicorn[standard] >= 0.30, rich >= 13.0, packaging >= 23.0

## Directory Structure
- `aioncode/` — Python package (47 files, ~6,500 lines)
  - `main.py` — CLI entry point (argparse, 8 subcommands)
  - `commands/` — 8 CLI command modules (init, install, uninstall, upgrade, dashboard, doctor, version, clean)
  - `core/` — Project initialization logic, path resolution
  - `utils/` — console (Rich), platform, integrity, network (4 modules, ~850 lines)
  - `internal/dashboard/` — Modular FastAPI application
    - `app.py` — Factory `create_app(dev=bool)`
    - `config.py` — Paths, constants, config resolution
    - `routers/` — 9 route modules (~590 lines): projects, monitor, files, bugs, team, commands, skills, browse, logs
    - `services/` — 8 business logic modules (~970 lines): project_registry, file_ops, team, skills, monitor, stats, bugs, encoding
    - `frontend/static/` — Dev-mode HTML/JS/CSS (index.html, app.js, views.js, style.css, views.css, monitor.html)
    - `frontend/embedded.py` — Autogenerated production bundle (~1,970 lines)
    - `frontend/build_frontend.py` — Static → embedded.py 构建脚本
    - `templates/` — Project scaffolding (CLAUDE.md.tpl, aion/ config, rules, hooks, checklists, settings)
- `commands/` — 18 AionCode slash command files (Markdown prompts)
- `templates/` — Installation templates
- `tests/` — 6 test files
- `docs/` — Design docs
- `.aion/` — Project intelligence directory (dogfooding)
- `.claude/` — Claude Code configuration (hooks, settings, installed commands)

## Entry Points
- `aioncode` CLI — 8 subcommands: init, install, uninstall, upgrade, dashboard, doctor, version, clean
- `aioncode dashboard` — Launches FastAPI on port 19200 (双进程架构: main process handles signals, child runs uvicorn)
- `aioncode dashboard --dev` — Dev mode: serves static files, enables /api/docs

## Key Patterns
- **Factory pattern**: `create_app(dev=bool)` — CORS、lifespan、router 注册
- **Router/Service 分层**: Router 处理 HTTP，Service 处理业务逻辑
- **Dual-mode frontend**: Production 用 embedded.py (autogenerated)，Dev 用 static/ 直出
- **Path encoding**: Base64 URL-safe encoding for project paths (`encoding.py`)
- **CLAUDE.md merge**: `<!-- AIONCODE:START/END -->` markers for idempotent content replacement
- **Custom YAML parser**: Hand-written state machine in `team.py` service (zero-dep constraint)
- **Event streaming**: SSE via `.aion/monitor/events.jsonl` with 2s polling and keepalive
- **File-driven collaboration**: All intelligence in `.aion/` (git-tracked), teams sync via commits
- **Commands are pure Markdown**: No executable code, interpreted by Claude Code at runtime
- **Embedded frontend build**: `build_frontend.py` reads static/ → generates embedded.py

## Build & Run
- Dev: `pip install -e ".[dev]" && aioncode dashboard --dev`
- Production: `pip install aioncode && aioncode dashboard`
- Test: `pytest tests/`
- Lint: `ruff check aioncode/`
- Build frontend: `python aioncode/internal/dashboard/frontend/build_frontend.py`
- Install to project: `aioncode init` (in target directory)

## Known Gaps
- Test coverage minimal (6 files, no integration/E2E tests for dashboard)
- No authentication/authorization on dashboard (assumes local/trusted network)
- Monitor SSE polls every 2s (no file watcher)
- models/ directory largely empty (dict responses instead of Pydantic models)
- Frontend: no TypeScript, no bundler, no component framework, no state management
- Team YAML parser is hand-written state machine (fragile)
