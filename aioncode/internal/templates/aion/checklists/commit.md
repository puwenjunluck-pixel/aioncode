# Commit Checklist

<!-- Customize this checklist for your project. Used by /aion-commit. -->

## Pre-Commit
- [ ] All changes shown to user
- [ ] No secret files staged (.env, credentials, API keys)
- [ ] Commit message accurately reflects changes
- [ ] Commit message follows type convention (feat/fix/refactor/docs/test/chore)

## Post-Commit
- [ ] Changelog updated
- [ ] Git commit succeeded (verified with git log -1)
- [ ] No unintended files committed
